Use the saved package

Extract the ZIP into a short local path and open this index. The report viewers use included local scripts and data. If a browser restricts local files, run python -m http.server 8878 --bind 127.0.0.1 from the extracted folder and open http://127.0.0.1:8878/. No external website or AI service is needed to view these results.

The complete raw recordings and ENVI cubes are not included. Selected linked source photographs are included. Original provenance files retain the acquisition-machine paths as evidence; recomputing from raw recordings requires those inputs and updated paths.
