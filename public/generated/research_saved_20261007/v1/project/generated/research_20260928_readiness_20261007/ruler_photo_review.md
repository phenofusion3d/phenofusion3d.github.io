# Five-plant ruler photograph review

Reviewed all **74 source images**: nine annotated overviews and 65 supporting photographs. 62 images were inspected individually; 12 additional context images were inspected in contact sheets. Every ruler-derived number below comes from an individual image review. Source hashes were checked against the prior inventory.

**18 of 47 dimensions have approximate photo-readable reference candidates. None is yet eligible for final numerical 3D validation**, because the same reconstructed physical organ/specimen and compatible measurement definitions have not been frozen. An unreadable photograph does not prove the operator measurement is wrong.

**Per-dimension categories:** 18 approximate photo-supported candidates (7 lengths, 11 widths); 21 operator-annotation-only dimensions (five heights and 16 organ dimensions); eight P4 dimensions unusable for leaf validation until organ type is resolved. These mutually exclusive categories total 47. No new exact ground truth is claimed. None of the photographed width sections is independently demonstrated to be the global maximum width.

Source values remain unchanged. All values below are centimetres. Photo ranges are visual-reading intervals, not statistical confidence intervals or calibrated uncertainty. Sources are relative to `data/main/test_plant_10-7/manual_validation_5-plants_28-09/`.

The user defined height as stem base (their wording was "step base") to the very tip, and stated that two rulers were used. None of the five saved height sets supports an independent precise base/junction/tip recomputation. Heights remain available as **operator-reported** references, separately labelled. For two rulers the calculation must be `(lower_at_join - lower_at_base) + (upper_at_tip - upper_at_join)`, not an assumed 30 cm plus a tip mark.

**P1 upper-blade width:** the annotation says **9 cm**. In `plant-1/Media (6).jpeg`, the photographed blade edges are approximately **0.2 cm and 1.0 cm**, so endpoint subtraction gives **0.8 cm**, with a cautious visual interval **0.6–1.0 cm**. The earlier 0.9 cm proposal falls inside that interval, but is not forced as an exact value. The diagnostic crop is `ruler_diagnostics/P1_upper_blade_width.png` (source rectangle 650,170,1110,500; enlarged 3×). This establishes the photographed section only, not the maximum width.

**P1 O04 is a cereal ear**, excluded from leaf statistics. **P4 organs remain uncertain leaf-versus-pod structures**, excluded from leaf statistics pending confirmation.

## Identity and research use

The stable O01/O02 IDs identify overview annotations, not acquisition folder numbers. Candidate folder correspondences are P3 O01→Leaf-5, O02→Leaf-4, O03→Leaf-3, O04→Leaf-2, O05→Leaf-1, O06→Leaf-6; P5 O01→leaf-4, O02→leaf-3, O03→leaf-2, O04→leaf-1, O05→leaf-5. Context and organ appearance support these candidates, but matching by numbers alone is prohibited. The JSON contains all photo paths, source SHA256 values, tentative RGB frame candidates and per-dimension status.

For every photo candidate, first confirm the physical organ using its attachment, shape, damage and overview context; then compare the same base/tip and photographed section. Held-flat photographic lengths may differ from in-situ curved lengths. Do not silently equate photographed section width with maximum width. Ear body must be distinguished from awns; P4 needs an organ-type decision.

All references remain **held out from camera calibration, depth-scale estimation, reconstruction tuning and spectral registration tuning**. Once calibration/reconstruction parameters and identities are frozen, report readable and operator-reported reference groups separately and include exclusions, visual intervals, unknown ruler calibration, parallax, pose differences and missing repeats.
