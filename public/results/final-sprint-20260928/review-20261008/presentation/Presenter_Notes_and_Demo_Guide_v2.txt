SLIDE 12: Dense projection diagnostic

The new experiment explicitly tests whether a dense visualisation can be recovered from the September data. SLIDE 17: Appendix: questions to expect

Q: Is the reconstruction perfect? A: It preserves observed surfaces, but missing views and weak depth leave gaps. We have not established complete coverage or independent physical accuracy. Q: Why do we have manual measurements but no full accuracy score? A: We must compare the same organ and endpoints. The operator references are retained, and conditional comparisons are useful, but missing or mismatched anatomy can invalidate a pooled score. Q: Why only three spectral markers? A: These are six measured spectra at three provisional 3D source locations. The dense extension has a separate correspondence problem. Q: Does a low plane-calibration error solve leaf mapping? A: No. Elevated leaf tests currently fail. Q: Can the software run offline? A: Processing and review are local. Generalisation and a laboratory hardware run still need separate testing. Q: What is the main contribution? A: A reproducible local workflow with metric geometry, source identities, both spectral sensors and explicit failure diagnostics, plus a concrete route to stronger validation.

SLIDE 20: Appendix: signal normalisation and quality

Raw DN is the recorded camera value. W denotes the observed white-board signal and D the assumed scan-tail offset. Q subtracts that assumed offset from the sample and reference, while Q0 tests a zero-offset alternative. The real dark acquisition and white reflectance were not independently confirmed, so neither is calibrated reflectance. Missing reference support keeps normalised values missing. Both red source locations lack valid normalised reference coverage. The green source location supports finite values in both sensors. We preserve those masks rather than fill missing spectra or copy a value onto adjacent geometry.

SLIDE 23: Appendix: offline operation and automation

The software does not need an AI service to run the added extraction and review actions. However, accepting a new compatible input file is different from automatically solving every scientific correspondence. The current research workflow still uses reviewed regions, organ identities, endpoint selections and spectral associations. The new thirteen leaf comparisons are manually reviewed research outputs. New local dense experiments also need their own supplied leaf regions and fitting evidence. We should demonstrate that boundary clearly. Reproducibility means a saved setup can replay the procedure. Generalisation requires new datasets and an evaluation with less or no bespoke setup.
